# 📚 Đánh giá Nguồn thông tin Học thuật: Trực quan hóa Git DAG

## 📖 Giới thiệu
Báo cáo đánh giá nguồn thông tin học thuật thuộc lĩnh vực Khoa học Máy tính. Tập trung vào việc thu thập, phân tích và đánh giá độ tin cậy của các tài liệu liên quan đến **Phương pháp trực quan hóa cấu trúc dữ liệu Đồ thị có hướng không chu trình (DAG) và Lịch sử tiến hóa phần mềm trong hệ thống Git**.

Dự án bao gồm việc sàng lọc và đánh giá chi tiết 13 nguồn tài liệu uy tín từ các tạp chí khoa học (IEEE Xplore), sách chuyên khảo và các blog kỹ thuật hàng đầu.

## 🚀 Nội dung chính
- Giao diện dark-mode Data Observatory với animated DAG diagram
- Bảng tổng hợp và đánh giá 13 nguồn, color-coded theo loại tài liệu
- Phân tích chuyên sâu 3 trục: DAG, AST, DevOps
- Danh mục tài liệu tham khảo theo chuẩn Harvard

## 🛠️ Tech Stack
- **React** + **TypeScript** + **Vite**
- **Tailwind CSS v4** + **Framer Motion**
- **JetBrains Mono** font
- GitHub Actions → GitHub Pages auto-deploy

## 💻 Chạy local
```bash
pnpm install
pnpm run dev
```
